# Product

## Register

brand

## Users

AKWE 2026 attendees in Cebu, primarily using their phones in a busy event hall, plus the event host preparing the task bag and sharing the invitation. Participants may be meeting one another for the first time and need to identify a person, enter their PlayerCode, and confirm a task quickly.

## Product Purpose

Human Bingo is a verified social icebreaker for AKWE 2026. Hosts create a task bag, attendees join without creating an account, and each participant receives a randomized 5×5 board. A square counts only after the identified participant confirms it. Success means attendees can complete the full join-to-verification loop quickly and the shared game remains authoritative for 300 concurrent participants.

## Brand Personality

Tactile, festive, mischievous. The interface should feel like a hand-assembled event scrapbook brought to life, with the care and clarity of a real game tool.

## Anti-references

- Generic SaaS dashboards and blue admin templates.
- Purple-gradient AI landing pages, mesh gradients, and glassmorphism.
- Stock photos, generic clip-art, or invented event metrics.
- Decorative maximalism that makes task text, controls, or the 5×5 grid hard to read on a phone.

## Design Principles

1. Let the supplied AKWE 2026 assets carry the event identity.
2. Make the next game action obvious, especially while attendees are moving through a noisy venue.
3. Treat verification as a social promise: a confirmed square gets one of the supplied face-stamps.
4. Keep the board readable at arm's length; decoration never replaces the task or accessible status.
5. Make every screen feel cut-and-pasted from the same event kit, not assembled from generic SaaS components.

## Accessibility & Inclusion

Target WCAG 2.2 AA. Preserve semantic form labels, keyboard access, visible 3px focus indicators, text status in addition to color or imagery, reduced-motion preferences, 44px minimum touch targets, 320px viewport support, and responsive zoom/reflow. Avoid relying on small text inside the supplied stamp art to convey information.
